# IL Rang

Appli mobile de missions quotidiennes avec XP, rangs (Novice → Nation) et historique.

## Installer sur le téléphone
1. Activer GitHub Pages : Settings → Pages → Branch = celle qui contient ces fichiers, dossier `/ (root)`.
2. Ouvrir l'URL Pages sur le téléphone.
3. iPhone (Safari) : Partager → « Sur l'écran d'accueil ». Android (Chrome) : menu ⋮ → « Installer l'application ».

Les données restent sur le téléphone (localStorage). L'appli marche hors ligne.
